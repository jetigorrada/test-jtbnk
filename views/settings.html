Save one or more chatbox embed snippets. Pick a render mode so it works no matter how the widget is delivered:
• sandbox — pastes any HTML/JS snippet into an isolated iframe (best default, safest).
• inline — injects the snippet directly into the live page (use if the widget must attach to the real page body).
• iframe-url — the code field is just a URL loaded in an <iframe>.
• script-url — the code field is just a URL loaded as an external <script src>.
